# Предложка

Telegram-бот на Python / aiogram 3 для анонимной предложки. Пользователь отправляет текст или медиа, оба администратора получают копию сообщения и карточку модерации.

## Возможности

- **Принять** — копирует исходное сообщение (включая медиа и альбомы) в подключённую группу или канал, затем отправляет под ним английский дисклеймер в формате цитаты и меняет статус карточки на «Принято».
- **Отклонить** — сообщает отправителю, что предложение не принято.
- **Ответить** — открывает режим ответа на 15 минут. Исходное сообщение автоматически прикладывается к ответу как цитата. Кнопка «Отменить ответ» завершает режим раньше.
- **Заблокировать** — запрещает пользователю отправлять новые предложения. Блокировка сохраняется в SQLite после перезапуска. При необходимости любой администратор может снять блок командой `/unblock USER_ID`.
- Карточки и кнопки есть у обоих администраторов; обработка одной заявки обновляет карточки у всех и предотвращает повторную модерацию.
- Поддерживаются текст, фото, видео, видеосообщения-кружки, голосовые, GIF, стикеры, файлы и альбомы.
- Сообщение для канала копируется без указания автора.

## Установка

1. Создай бота через [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Установи зависимости: `pip install -r requirements.txt` (Python 3.11+).
3. Скопируй `.env.example` в `.env` и заполни `BOT_TOKEN`.
4. Запусти `python main.py` или `bash start.sh`. На BotHost команда запуска — `python main.py`.
5. **Оба администратора должны открыть бота и нажать `/start`**, иначе Telegram не даст боту написать им в личку. ID администраторов задаются через `ADMIN_IDS=8798455134,438672098`.
6. Добавь бота в группу `-5106639548` (либо администратором канала с правом публикации). Чат для публикаций по умолчанию — `-5106639548`. При нажатии «Принять» бот копирует туда исходное сообщение, включая медиа и альбомы, и отправляет под ним английский дисклеймер в формате цитаты. Любой из двух администраторов может изменить место публикации командой `/channel @username` или `/channel CHAT_ID`.

Для Docker можно передать переменные окружения, например: `-e BOT_TOKEN=... -e ADMIN_IDS=8798455134,438672098 -v /your-data:/data -e DB_PATH=/data/suggestions.sqlite3`. Сохраняй файл SQLite между перезапусками.

## Premium emoji

Бот читает публичный набор [vector_icons_by_fStikBot](https://t.me/addemoji/vector_icons_by_fStikBot) через `getStickerSet` и подбирает подходящие custom emoji. Для подтверждения используется указанный premium emoji ID `5219899949281453881`. Если набор недоступен или Telegram не принимает custom emoji, бот переключается на обычные символы.

## Важно

- Не размещай токен бота в репозитории — используй переменные окружения или локальный `.env`.
- Не удаляй и не сбрасывай базу SQLite: в ней хранятся заявки, подключённый чат для публикаций и блокировки пользователей.
- Не запускай два экземпляра polling-бота одновременно с одним токеном.
- Если Telegram ещё не разрешил боту написать админу, админ должен открыть чат с ботом и нажать `/start`.
- Если после нажатия «Принять» возникла неоднозначная ошибка публикации, бот не повторяет публикацию автоматически, чтобы избежать дубликатов; проверь группу или канал вручную.
