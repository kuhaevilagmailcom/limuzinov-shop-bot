# LIMYZINOV SHOP

Telegram-магазин, админ-панель, поддержка и обработчики оплат в одном Python-процессе. Публичного сайта нет. Отдельный сервер базы данных не нужен: SQLite создаётся в `data/shop.db` рядом с приложением.

Интерфейс работает как один аккуратный экран: перед показом нового сообщения бот удаляет свой предыдущий экран. Во вложенных разделах есть контекстная кнопка «Назад», а главное меню всегда доступно отдельной кнопкой.

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m app.main
```

Для Windows активация окружения: `.venv\Scripts\activate`. Минимально в `.env` нужен только `BOT_TOKEN`. Способ оплаты появляется в боте лишь тогда, когда для него заполнены ключи.

## RollyPay

Заполните `ROLLYPAY_TERMINAL_ID`, `ROLLYPAY_API_KEY` и `ROLLYPAY_SIGNING_SECRET`. В настройках кассы укажите Callback URL:

```text
https://ваш-домен.ru/rollypay/callback
```

Сначала проверьте полный цикл с `ROLLYPAY_TEST_MODE=true`, затем включайте боевой режим. Callback проверяет HMAC-подпись, ID заказа, ID платежа, валюту и сумму. Каждый заказ имеет UUID, повторная доставка callback не засчитывает покупку второй раз, а безопасный журнал сохраняет результат события и число его доставок.

## Админ-панель и каталог

Владелец с Telegram ID `8464597898` уже указан в коде — добавлять его в `.env` не нужно. После запуска отправьте боту `/admin`. Переменная `ADMIN_IDS` остаётся необязательной и нужна только для добавления других администраторов через запятую.

Готовых товаров в каталоге нет. В админ-панели можно создавать свои товары, менять цену СБП и цену в Stars, редактировать название/описание и скрывать позицию. Для каждого товара обязательны обе цены; покупатель выбирает СБП или Telegram Stars. Каталог хранится в `data/shop.db`, редактировать Python-файлы не нужно.

Там же доступны промокоды, аналитика и журнал оплат. Аналитика показывает число пользователей, продажи за 24 часа/7 дней/30 дней, конверсию пользователей в покупателей и популярные товары. Рубли и Stars считаются отдельно.

## Бонусы и реферальная программа

В разделе «🎁 Бонусы» пользователь видит баланс, вводит промокоды, историю начислений и персональную ссылку. За нового приглашённого пользователя начисляется 100 бонусов пригласившему и 50 бонусов приглашённому. Повторная регистрация, повторное использование промокода и самоприглашение не начисляют бонусы.

## Поддержка

Кнопка «💬 Поддержка» принимает текст, фото, видео, документы и голосовые сообщения. Обращение сохраняется в SQLite и отправляется владельцу `8464597898`. Владелец отвечает покупателю кнопкой «✉️ Ответить», может просматривать новые, все и закрытые обращения в `/admin`. Для сообщений действует защита от спама.

## Хостинг

Команда запуска: `python -m app.main`. Технический HTTP-сервис слушает `0.0.0.0:8080`. Доступны только `GET /health`, `POST /rollypay/callback` и `POST /webhooks/rollypay`; запрос к `/` возвращает 404. Можно использовать готовый `Dockerfile`.

Папка `data/` должна храниться на постоянном диске. Секреты задавайте через `.env` или панель переменных окружения хостинга; `.env` исключён из Git.
