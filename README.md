# Предложка колледжа

Telegram-бот на Python/aiogram 3: `/start` → отправка текста, фото, видео, кружка, голосового, GIF, стикера, файла или альбома → сообщение модератору **6341678542** → кнопки **Принять / Отклонить** → публикация в выбранный канал без информации об авторе.

Копия сообщения поступает админу без метки «переслано». Под ней карточка по образцу: «Новое сообщение», разделитель, username, Telegram ID, имя, дата и время. Кнопки цветные (зелёная/красная) в поддерживаемых Telegram-клиентах; статусы обновляются после модерации. Автору приходит именно **✅ Предложение отправлено на проверку.** с пользовательским premium emoji ID `5219899949281453881`.

## Установка

1. Создай бота в [@BotFather](https://t.me/BotFather), скопируй токен.
2. Поставь зависимости: `pip install -r requirements.txt` (Python 3.11+).
3. Скопируй `.env.example` → `.env` и заполни `BOT_TOKEN`.
4. Запусти `python main.py` или `bash start.sh`. На BotHost команда запуска `python main.py`.
5. Админ с ID `6341678542` **сам нажимает `/start`**, добавляет бота в канал с правом публикации, бот уже настроен на канал **-1004422721133**. Для изменения канала есть `/channel @имя_канала` или `/channel -100...`.
6. При старте бот удаляет старые команды магазина с серверов Telegram. У пользователей в меню только **/start**, у администратора — **/start** и **/channel**. После обновления перезапусти процесс.

Для Docker: `docker build -t college-suggest .` и передай переменные `-e BOT_TOKEN=... -e ADMIN_ID=6341678542 -v /your-data:/data -e DB_PATH=/data/suggestions.sqlite3`. SQLite нужно сохранять между перезапусками.

## Premium emoji

Бот читает публичный набор [`vector_icons_by_fStikBot`](https://t.me/addemoji/vector_icons_by_fStikBot) через `getStickerSet` и подбирает custom emoji по стандартному emoji (🤖, 🪪, 👤, 🕓, ❌). Для подтверждения используется **точно** указанный ID `5219899949281453881`. Если подходящий эмодзи в наборе не найден, показывается обычный символ. Если Telegram не разрешает премиум-эмодзи или иконки в кнопках, бот повторяет отправку с обычными эмодзи. Премиум-функции Telegram могут требовать Premium у владельца бота.

## Важно

- Никаких старых магазинных файлов в новой `main`-ветке нет. История прежнего проекта остаётся в Git и доступна по предыдущим коммитам.
- Токен **никогда не размещай в репозитории** — используй переменные окружения или локальный `.env`.
- Сохраняй базу SQLite, чтобы не потерять заявки и привязку канала.
- Не запускай два экземпляра polling-бота одновременно с одним токеном.
- Команды Telegram кешируются клиентом; после рестарта бота список обычно обновляется при повторном открытии чата. Команды из специфических прежних индивидуальных scope могут потребовать отдельной очистки.
- В редком случае неоднозначного ответа Telegram после отправки в канал автоматический повтор выключен, чтобы избежать дубликатов; админ должен проверить канал вручную.
