# Предложка

Telegram-бот на Python и aiogram 3: пользователь отправляет сообщение боту в личку, а бот **сразу копирует его в заданную группу или канал**. Модерации и админского подтверждения нет.

## Возможности

- Мгновенная публикация текста и поддерживаемых Telegram медиа: фото, видео, видеосообщения-кружки, голосовые, аудио, GIF, стикеры и файлы.
- Альбомы собираются в течение короткой паузы и отправляются в группу или канал одним альбомом.
- Сообщение копируется без указания отправителя.
- Пользователь получает уведомление об успешной публикации.
- Чат для публикаций задаётся переменной окружения. Старое значение, уже сохранённое в SQLite, сохраняется при обновлении.

## Установка

1. Создай бота через @BotFather и скопируй токен.
2. Установи зависимости командой pip install -r requirements.txt (Python 3.11+).
3. Скопируй .env.example в .env и заполни BOT_TOKEN.
4. Проверь DESTINATION_CHAT_ID. По умолчанию это -5106639548. Старое имя переменной CHANNEL_ID тоже поддерживается.
5. Добавь бота в указанную группу или канал. В канале выдай боту право публиковать сообщения.
6. Запусти python main.py или bash start.sh. На BotHost команда запуска — python main.py.

Для Docker можно передать переменные окружения, например: -e BOT_TOKEN=... -e DESTINATION_CHAT_ID=-5106639548 -v /your-data:/data -e DB_PATH=/data/suggestions.sqlite3. Сохраняй файл SQLite между перезапусками.

Если в существующей базе SQLite уже был сохранён адрес другого чата, бот продолжит использовать его. Для новой базы укажи нужный ID в DESTINATION_CHAT_ID.

## Важно

- Не размещай токен бота в репозитории — используй переменные окружения или локальный .env.
- Не удаляй файл SQLite, если хочешь сохранить ранее настроенный чат для публикаций.
- Не запускай два экземпляра polling-бота одновременно с одним токеном.
- Служебные сообщения Telegram, которые нельзя копировать через Bot API, не публикуются.
- Если Telegram не подтверждает результат копирования, бот не повторяет отправку автоматически, чтобы не создавать дубликаты. Проверь группу или канал вручную.
