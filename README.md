# Предложка с модерацией в группе

Telegram-бот на Python 3.11+ и aiogram 3. Пользователь отправляет сообщение боту в личку, а заявка появляется в группе модерации. Для альбомов бот дополнительно создаёт карточку управления с кнопками, чтобы модерация оставалась доступной даже если Telegram не показывает клавиатуру на элементах альбома. Отдельные администраторы и их личные чаты не нужны: кнопками может пользоваться любой участник группы.

## Возможности

- Поддерживаются текст, фото, видео, кружки, голосовые, GIF, стикеры, файлы и альбомы.
- Для одиночного текста или медиа кнопки находятся на исходном сообщении; после решения текст/подпись обновляется на месте.
- Если длинная подпись или текст не оставляют места для данных отправителя в лимите Telegram, бот сохраняет исходный контент и добавляет отдельную карточку с именем, @username и ID отправителя.
- Альбомы остаются альбомами. Бот пытается прикрепить кнопки к каждому элементу и всегда добавляет отдельную карточку управления с рабочими кнопками; успешно прикреплённые кнопки не удаляются.
- Пока решение не принято, в карточке не выводится строка «Статус: на проверке». После решения указывается итог и имя с Telegram ID модератора.
- Принять — публикует исходное предложение в целевом канале и добавляет дисклеймер в конце в формате Telegram-цитаты. Если подпись/текст слишком длинные или тип сообщения не поддерживает подпись, дисклеймер отправляется ответом к посту; если Telegram не разрешает ответ, он публикуется отдельным цитируемым сообщением.
- Отклонить — сообщает отправителю, что предложение не принято.
- Ответить — после нажатия кнопки можно ответить на сообщение-подсказку или прямо на карточку заявки; ответ уходит пользователю в личку с цитатой его предложения.
- Заблокировать — блокирует пользователю отправку новых предложений. Блокировки сохраняются в SQLite. Участника группы модерации бот заблокировать не даст; если такой участник был заблокирован ранее, при следующем обращении бот снимет блокировку после подтверждения его членства.
- Команда /top в группе модерации показывает рейтинг модераторов по числу обработанных заявок и статистику опубликованных постов за сегодня, последние 7 дней и текущий месяц.
- Команды /users и /done доступны любому участнику группы модерации: /users показывает постраничный список пользователей с именем, @username и ID; /done ТЕКСТ запускает подтверждаемую рассылку, а ответ командой /done на сообщение рассылает это сообщение.
- Команда /help показывает доступные команды.
- Команда /unblock USER_ID в группе модерации снимает блокировку.
- Команда /cleanbuttons, отправленная ответом на сообщение в группе модерации, убирает клавиатуру именно с этого сообщения. Команда /cleanbuttons POST_ID убирает клавиатуру у поста в канале публикации; POST_ID — число в конце ссылки.
- После решения кнопки убираются со всех элементов заявки, повторно обработать её нельзя; на карточке указываются имя и Telegram ID модератора, который принял, отклонил или заблокировал пользователя. Если сообщение нельзя редактировать, информация о решении отправляется ответом на карточку. При запуске бот обновляет клавиатуры ожидающих заявок (заменяет старые кнопки на актуальные) и очищает клавиатуры обработанных карточек.
- Иконки интерфейса используют набор [TgAndroidIcons](https://t.me/addemoji/TgAndroidIcons): в сообщениях — custom emoji, на кнопках — встроенные иконки Telegram. При явном отказе API бот повторяет отправку с обычными emoji.

**Важно:** для отображения именно custom emoji у владельца бота должен быть Telegram Premium. Иконки в сообщениях доступны в личных чатах, группах и супергруппах; в канал копируется исходное содержимое пользователя, а в конце добавляется цитируемый дисклеймер.

## Настройка

1. Создай бота через @BotFather.
2. Установи зависимости: pip install -r requirements.txt.
3. Укажи BOT_TOKEN в переменных окружения хостинга или в локальном .env.
4. Укажи MODERATION_CHAT_ID — ID группы, куда приходят заявки и кнопки.
5. Укажи DESTINATION_CHAT_ID — ID отдельного канала, куда отправлять принятые предложения. Эти ID должны быть разными, если нужна публикация из группы в канал.
6. Добавь бота в группу модерации и укажи её ID в MODERATION_CHAT_ID. Чтобы проверка членства работала надёжно и бот мог защищать участников группы от блокировки, выдай боту права администратора в группе. Для канала добавь бота администратором с правом публикации и укажи ID именно канала.
7. На BotHost команда запуска — python main.py. После изменения кода или переменных окружения полностью перезапусти приложение, чтобы запустился новый процесс.

Пример переменных окружения:

- BOT_TOKEN — новый токен бота.
- MODERATION_CHAT_ID=-5106639548 — группа модерации (пример).
- DESTINATION_CHAT_ID=-1001234567890 — отдельный канал публикации (пример; используй свой реальный ID).
- DB_PATH=/data/suggestions.sqlite3 — необязательно; путь к базе SQLite.

Если используется существующая SQLite-база, старые заявки и блокировки сохраняются. Пользователи из старых заявок автоматически попадут в список /users; новые пользователи записываются при первом обращении в личный чат с ботом. Для заявок, опубликованных до установки этой версии, статистика периодов использует дату создания заявки как приблизительную замену времени публикации; новые публикации получают точную отметку времени. Явная переменная DESTINATION_CHAT_ID имеет приоритет над старым адресом, сохранённым в базе.

## Важно

- Все команды в группе модерации доступны любому участнику группы. В частности, любой участник может просматривать список пользователей и запускать массовую рассылку через /done; перед отправкой бот всё равно показывает подтверждение.
- Не добавляй токен в GitHub. Храни его только в защищённых переменных окружения хостинга.
- Не запускай два экземпляра polling-бота одновременно с одним токеном.
- Старая кнопка «Связаться с владельцем» была клавиатурой в личном чате пользователя, а не кнопкой под постом. При команде /start и при отправке уведомления бот снимает такую клавиатуру; если она осталась видна, нажми /start один раз. Убрать клавиатуру из чата, в который пользователь не отправляет сообщений, бот не может. После решения заявки кнопки модерации удаляются со всех известных элементов и карточки управления. Исторические посты канала нельзя автоматически перебрать через Bot API, если их ID не сохранены; для них используй /cleanbuttons POST_ID. Новые публикации бот отправляет без inline-кнопок.
- Если /start не отвечает после деплоя, проверь логи запуска: в них должно быть Started as @... . Убедись, что хостинг запустил нужную ветку и что не работает второй экземпляр бота с тем же токеном.
- Если в логах написано, что группа модерации и канал публикации имеют одинаковый ID, бот не будет считать заявку опубликованной: укажи разные ID.
- Если текст нужно опубликовать вместе с фото или видео, отправляй текст именно в подписи к медиа. Telegram не позволяет превратить два отдельно отправленных сообщения в одно без изменения исходного содержимого.
